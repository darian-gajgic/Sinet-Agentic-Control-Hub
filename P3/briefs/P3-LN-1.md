## 1. Scope walls (read first)

- **Substrate only.** No provider entry, no credential, no lane commissioning, no routing/seat changes. `internal/worker` routing, `resolveSeat`, and the §288 consumer-class posture ("class (a) has no v0 consumer") are **untouched** — that text stays true per-lane until LN-2/LN-3.
- **$0 absolute.** No live network call to any provider. Tier F is fixtures/fake-serve; tier R is a REAL local serve process probed at zero provider cost (loopback only, fake provider endpoint where a provider is needed); tier L is a stub that always skips at LN-1 (see §8).

The `sinet-engine@` DRAFT skeleton in `internal/units` (its `ExecStart` was left to "S03/S11.8 at B1", CONVENTIONS §7) is **deliberately NOT completed here** — it batches with lane commissioning/host ceremony. Dev posture = the platform spawns per-user engine subprocesses itself (STATE LN-1 row; S01.2/S01.3 process seam).
- **`web/src` untouched. `Spec/`, `Docs/`, `Research/`, `P3/STATE.md` read-only.** No new Go dependency (stdlib + existing internal packages suffice; opencode is an external CLI, not a Go module — the claude-engine precedent: no `modules` claim).
- **No metering logic.** Adapters forward usage/limit signals as raw data; the taxonomy and pricing live in S10 (already built). Never price from opencode's `.cost` (S03.7).
- **Adopt, don't fork.** opencode runs unmodified; integration is config/env/HTTP only (S16.1). `POST /global/upgrade` is never exposed or called (S03.3 rule 2).
- **Don't add features, refactor, or introduce abstractions beyond what this packet requires.**

Health-watch polls `/api/health` **with Basic auth** (R4). Shutdown reaps the process group. **R4 — Per-instance server password [S03.2; SPIKE P2-S1].** Mint `OPENCODE_SERVER_PASSWORD` per instance start from `crypto/rand`; opencode enforces it as HTTP **Basic** auth on **every** endpoint **including `/api/health`** — the adapter client AND the health-watcher both send it on every request. The password lives in process memory and the child env only: **never** in logs, run_events, the DB, fixtures, park records, or test output (D2 hygiene extended; CONVENTIONS §10 credential hygiene).

**R5 — start verb [S03.1 table; S02.4b].** `POST /session` + `POST /session/{id}/prompt_async` with per-message `model:{providerID,modelID}` and `agent` selected **by name** [SPIKE G1-S3]. The Cursor carries the engine-REPORTED session id (never assumed), `Substrate: "opencode"`, MessageIndex; `TranscriptPath` stays empty — opencode has no JSONL transcript (its store is SQLite `event`/`event_sequence`); the Driver's copy-aside is naturally inert (`CopyAsideDir` path requires a TranscriptPath), and `engine_sessions` upkeep still runs through the existing Driver.

**R6 — stream verb [S03.1, S03.4].** Subscribe **v1 `GET /event`** for `permission.asked`/`permission.replied` — the global v2 `/api/event` does NOT carry them in 1.18.3 [SPIKE P2-S1 Probe 6-B]. **Both event generations exist — parse tolerantly** [Probe 6-B]. Forward-tolerant parsing is a MUST: unknown event types logged and skipped, never fatal, never minted as new platform kinds (S03.1; adapters.go EventKind doc). Normalize to the closed platform set {message, usage, rate_limit, gate_ask, tool_result, done}; payload excerpts bounded at `adapters.ExcerptCap` (P-T07-5). An oversized/unparseable frame is a skipped frame, never a wedge (CONVENTIONS §60 pump doctrine).

**R7 — checkpoint & report_usage verbs [S03.1, S03.7, S02.4a; D4/D5].** Per-message token rows → one `Usage` event per paid call, grouped by message id; map `.tokens.{input,output,reasoning,cache.*}` into the Usage block (reasoning tokens: keep them in `Raw` verbatim; the typed fields carry what they can — never invent fields on the shared struct without need). **opencode's `.cost` is $0 on flat-rate lanes** [SPIKE P2-S1 Probe 7]: forward `EngineCostUSD` as a cross-check figure ONLY; the adapter never prices, never derives dollars (S03.7 "never meter dollars from opencode"; D5). Run totals ride the terminal envelope (`Total: true`), never a checkpoint. Limit signals: forward the `GET /session/status` `retry` variant (`attempt`, `next`, provider `action`) as `KindRateLimit` DATA [S03.1]; classification is S10's, not this packet's.

**R8 — gate parking, the S03.4 round-trip [S03.4; SPIKE P2-S1 Probes 1, 6].** `permission.asked` parks the turn at **zero cost** on an in-process deferred. The durable ask-record is a platform record **from the moment the ask is observed** (the existing Driver upserts it from `Event{Kind: KindGateAsk, Ask: …}` — the adapter's duty is a correct `Ask` + full-invocation `ParkRecord`). Enumerate **all** entries of the flat **`GET /permission`** array (`permission.list`); answer via **`POST /permission/{id}/reply {reply, message?}`** (keeps reject-with-feedback `CorrectedError`, unlike legacy `permission.respond`); key everything by **`requestID`**; **one `always`-class reply fans out to N `permission.replied` events** — parse that fanout tolerantly and resolve by requestID. **The adapter NEVER sends `"always"`** — v1 `always` rules are in-memory AND server-wide, leaking approvals across a person's sessions and vanishing on restart; emit only `once`/`reject`; persistent allow-policy is Sinet's own layer [Probe 6-A].

**R9 — restart-ask-loss containment [S03.4; SPIKE G1-S3 F4; P2-S1 Probes 2, 5].** Pending permission and question asks are in-memory Maps, rejected **silently** on graceful shutdown (no bus event) and lost on crash (#36347, unfixed). Containment: persist on `permission.asked` (R8); after any serve restart/health blip, **infer a dead park by diffing the platform ask-record against `permission.list`**; a dead park = "ask gone, session intact — re-prompt the surviving session to recover (a normal paid turn)"; the adapter marks the orphaned call cancelled in its **own** record — opencode leaves the transcript part cosmetically `running` and it is never trusted [Probe 2]. (At LN-1 the re-prompt is exercised against the fake serve only — it is a paid turn on a live lane.)

**R10 — HTTP-only origination [S03.4; SPIKE P2-S1 Probe 3].** Originate every turn over HTTP; never attach a TUI to a Sinet-owned serve (#16367 attach-hang is orthogonal to the HTTP path, measured immune; #36835 makes TUI-initiated asks unanswerable over REST).

**R11 — resume verb [S03.1, S03.4; S02.6].** Full-invocation re-supply semantics: when the engine still holds the ask, answer it via R8's reply (a defer-style unpark); when the serve lost it (R9), **re-prompt the surviving session id — a paid turn**. `ParkRecord.Start` is re-supplied whole; freshness-gating is the caller's (`Driver.DriveResume` already runs the S02.6 pass upstream). A park record without an engine session id is a named error (claudecli precedent).

**R12 — pause & cancel verbs [S03.1; P-T01-4].** Pause = interrupt-at-safe-boundary + park; never mid-tool-call. Cancel ladder: `POST /session/{id}/abort` (cooperative) → process-group TERM → KILL after a grace (plain constant, the `cancelGrace` precedent). A cancel that raced a completed result loses — the result stands (claudecli assembleOutcome precedent). Fork-from-checkpoint stays recovery's standard path (S02.5), not the adapter's.
