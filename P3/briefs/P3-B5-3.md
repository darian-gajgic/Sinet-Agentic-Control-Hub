## 1. Numbered requirements (each tagged with its S-ref)

### A — Tier 0: deterministic counters over the event log (S14.4 ¶Tier-0)

- **R1. Tier 0 is always-on, zero-cost, NO model, over `run_events`** [S14.4]. Every signature is computed over the run's B5-1-canonical event types (`tool.completed`, `run.state_changed`, `usage.recorded`, etc.). Tier 0 is **STATELESS**: each evaluation re-derives its counters from a **bounded recent-events window per active run** (the window bounded by the relevant ⚙ count) read fresh from `run_events` — **no durable watchdog cursor, no state table** (S14.1 "the event log IS the observability substrate"; §6). A restart re-derives from the log; nothing is lost.
- **R2. Loop** — identical tool-call signature (hash of tool name + serialized args) **⚙ `watchdog.loop_repeat`** (=5) × consecutive [S14.4]. Signature = a stable hash over the `tool.completed` payload's tool name + serialized args (use the **args digest** where present, never raw args — the B5-2/§30 discipline). Trips when the last `⚙ watchdog.loop_repeat` consecutive `tool.completed` events for the run share one signature.
- **R3. Ping-pong** — two-pair alternation **⚙ `watchdog.pingpong_cycles`** (=6) cycles [S14.4]. Trips when the run's recent tool-call signatures alternate A,B,A,B… for `⚙ watchdog.pingpong_cycles` cycles.
- **R4. Error-loop** — same action → error **⚙ `watchdog.error_loop`** (=3) × [S14.4]. Trips when the same tool/action yields an error `⚙ watchdog.error_loop` times in a row (error surfaced on `tool.completed` payload / an error event).
- **R5. Silence** — no event past the run-type's budget **⚙ `watchdog.silence_budget.<run_type>`** [S14.4]. This is **time-based (absence)** — evaluated on the periodic sweep (R28) against the newest `run_events` ts per **active** run (`state ∈ {new,queued,claimed,running,parked,draining}`). The map is empty at v0 → **each entry falls back to the `recovery.dead_after` seed (5 min)** until per-run-type calibration (the key's own help + `TBD-BRINGUP(per-run-type silence budgets from observed event cadence)`, S19.6, attached to B5-3 in STATE — **do not invent values; seed = `recovery.dead_after`**). A parked run whose park has an explicit resume-time is NOT "silent" (it is legitimately waiting) — exclude parked-with-resume from silence (guard against flagging a healthy limit-park).
- **R6. Spend** — daily per-person total > **⚙ `watchdog.spend_median_mult`** (=3×) × the trailing-14-day median, **armed only after ⚙ `watchdog.spend_arm_days`** (=14) days of history; **below that, ceilings only (the cold-start floor)** [S14.4]. Reads the **priced** ledger [S10/S14.10]. **v0 posture (BINDING honest state):** the price table ships EMPTY (§11) → every row UNPRICED → the spend rule has no dollars and stays at its cold-start floor (ceilings only). Build the machinery (daily per-person priced total + 14-day median + the arm-day gate) **dormant-but-tested**; it activates when a price table is seeded (B5-6/operator). Per-run ceilings themselves are enforced at S10.8/S02.2 — **the spend rule adds only the daily-total anomaly, never a ceiling** (do not re-implement ceilings).
- **R7. Suspicious completion** — run ended with anomalously low tool/verification activity for its class (the silent-failure class) [S14.4]. Evaluated at run **terminal** (on `run.state_changed`→`completed`): count the run's `tool.completed` + `verdict.recorded` events; below a per-class floor → flag. **No ⚙ is ratified for this floor** → it is a **structural constant** per run class (the `sseBatchSize` precedent, §7; a future operator knob is an S18 amendment). The honest v0 floor is conservative (e.g. a run that produced zero tool calls AND zero verdicts where its class expects them). A terminal run is not checkpointable → its Tier-1 disambiguation (if any) meters via the AdvisoryMeter platform-run path (R13).
- **R8. All thresholds are ⚙, seeded from prior art; the cold-start-floor rule binds spend** [S14.4]. **Every threshold above is read by dotted key at evaluation time** (live-apply, the §6/§7 re-read precedent) — **NONE hardcoded, NONE re-declared** (all in the S18 index).

## 2. The Tier-0 counter algorithms + ⚙ keys + the cold-start-floor rule (R1–R8)

Each counter is a **pure function** over a bounded slice of the run's recent `run_events` (re-derived each evaluation — stateless, R1). Signatures use the B5-1-canonical types.

| Rule | Algorithm (over the run's recent `run_events`) | ⚙ key (dotted) | Cold-start / dormancy |
|---|---|---|---|
| **loop** | hash(tool name + serialized args/args-digest) of the last N `tool.completed`; trip if the last **⚙ `watchdog.loop_repeat`** (5) are identical | `watchdog.loop_repeat` | — |
| **ping-pong** | signatures of recent `tool.completed`; trip if they alternate A,B,A,B… for **⚙ `watchdog.pingpong_cycles`** (6) cycles | `watchdog.pingpong_cycles` | — |
| **error-loop** | same tool/action → error **⚙ `watchdog.error_loop`** (3) × in a row | `watchdog.error_loop` | — |
| **silence** (time-based, sweep) | now − newest `run_events` ts for an **active** run > **⚙ `watchdog.silence_budget.<run_type>`** (map; empty entry → **`recovery.dead_after`** seed = 5 min) | `watchdog.silence_budget` (+ `recovery.dead_after` seed) | seed until `TBD-BRINGUP(per-run-type silence budgets)`; exclude parked-with-resume-time |
| **spend** (daily, sweep) | daily **priced** per-person total > **⚙ `watchdog.spend_median_mult`** (3×) × trailing-14-day median; armed only after **⚙ `watchdog.spend_arm_days`** (14) days | `watchdog.spend_median_mult`, `watchdog.spend_arm_days` | **DORMANT at v0** (empty price table → UNPRICED; and <14 d history) → **ceilings only** (S14.4 cold-start floor). Machinery built + tested. |
| **suspicious-completion** (terminal) | at `run.state_changed`→`completed`: count `tool.completed` + `verdict.recorded`; below a per-class structural floor → flag | none ratified → structural constant | conservative v0 floor; calibrate post-v0 |

**Propose a NEW `internal/watchdog`** package. Justification vs extending an existing package:

- **`internal/watchdog`** cleanly holds: the Tier-0 pure counters, the Tier-1 disambiguator adapter (imports `local`), the Tier-2 park+flag routing (imports `run`+`eventlog`), the suppress/retune logic, the alert-severity classifier, the 4 registered-check runners (consuming shell seams), and the dead-man probe.
