### D — The decision statistic, alarm, and gate (BENCH-REG §7/§8/§11/§12; S14.7)

- **R14 — G, exactly §7, stdlib only.** Per (domain, epoch) over non-tied pairs: `p ~ Beta(1+w, 1+(m−w))`; `G = P(p > 0.5)` computed exactly via the integer identity `G = P(Binomial(m+1, ½) ≤ w)`. Updated per pair, inspectable anytime, optional stopping — G is the ONLY decision input; fixed-n views are readouts (§7/§16). The §2 reference table (this brief, session-verified) is the pinned test fixture set — every row asserted exactly.
- **R15 — Tie handling, exactly §8.** tie/both-bad are excluded from m and w, never enter the posterior, and are first-class recorded signals: tie rate and both-bad rate report beside every win rate at the same n. No imputation, no re-votes, no re-pairing. Sustained high both-bad is a reporting-view signal with NO automatic decision consequence.
- **R16 — The alarm, exactly §12.** Trigger: at any per-pair update, `1−G > 0.95` in any launch domain's current epoch. Action: a **flag-now** card carrying the full record + a standing **expansion-freeze** state (the 14.5 hold — displayed and queryable; breadth is an operator act, so the freeze binds by visibility + gate limb (c), not by killing anything). Nothing is auto-killed; running work untouched (D1.3). The alarm stands while the condition holds; clearing requires an operator disposition logged as a decision event (§12; OQ4). Alarm history is keep-forever.
- **R17 — The gate, exactly §11 — evaluate + display, SET nothing.** Per launch domain over the current epoch: (a) m ≥ 20 non-tied, (b) G ≥ 0.90, (c) no active alarm, (d) the domain's regression suites green at registered floors — read through the evals surfaces (`Floor`/`CheckFloor`/`SweepState`) via a shell-root seam (R20): an unfloored/unratified/red/absent suite ⇒ limb (d) is honestly "not evaluable — gate cannot open", with the reason named (§10.1(d); §33 carry). The 15.3 gate opens when every registered launch domain passes (v0: software-development alone is the registered v0 roster; web-research accrues from v0.1). The evaluation writes NO gating state into any other subsystem — it is a readout consumed by displays and by the R3 phase logic.
